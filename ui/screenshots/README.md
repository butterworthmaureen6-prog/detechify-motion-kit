# UI screenshots

Drop scrubbed screenshots of real tools here, one folder per topic:

```
ui/screenshots/data-cleaning/   e.g. pgadmin-table.png, power-query.png
ui/screenshots/networking/      e.g. wireshark-capture.png
ui/screenshots/cybersecurity/   e.g. burp-history.png
ui/screenshots/ai/              e.g. chat-ui.png, token-usage.png
ui/screenshots/cloud-infra/     e.g. aws-console.png
```

Naming: `tool-what-it-shows.png` (lowercase, hyphens, no spaces). PNG, under 1 MB, 1920 px wide or less.

Before adding: blur or replace real IPs, hostnames, emails, tokens, keys, account IDs and client data. Only screenshots of your own screen or tools you may show. No other creators' frames.
